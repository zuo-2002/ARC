# 工业遗产改造案例分析：Tonsley 主装配厂房与南京压缩机厂尤家凹社区中心

## 研究目的

本分析服务于“广州 1935 发电厂干煤棚改造”个人设计任务，重点关注大跨度工业遗产如何转化为开放公共空间，以及结构保留、复合功能、景观介入、生态策略和交通组织之间的关系。

---

## 案例一：Tonsley Main Assembly Building and Pods

### 1. 项目基本信息

- **项目**：Tonsley 工业区主装配厂房及 Pods 改造
- **地点**：澳大利亚南澳大利亚州阿德莱德
- **设计**：Woods Bagot，与 Tridente Architects 合作
- **建成**：2015 年；园区后续持续建设
- **规模**：Tonsley 总体规划约 61ha，主装配厂房约 47,000㎡
- **原有性质**：三菱汽车工厂主装配厂房
- **新功能**：清洁技术、先进制造、教育科研、创业办公、商业及公共活动

该项目把原汽车制造厂转化为面向知识经济的创新街区。设计目标不是把厂房封闭成单一商业盒子，而是把工业遗存作为城市社区的骨架，使工作、教育、创业、公共活动和景观共同进入原有大空间。

### 2. 核心空间策略

**（1）保留“工业伞盖”，新功能作为可变单元植入。**

原有大跨度屋面和结构体系被保留为具有识别性的“umbrella”。新空间以 Pods、盒子和可调整的工作单元嵌入其中，形成“重结构 + 轻插入”的更新关系。原有结构负责历史表达和空间尺度，新插入体负责当代功能、围护和声热环境。

**（2）以公共性替代传统工业园区的封闭性。**

设计没有沿用“厂房—道路—停车场”的园区模式，而是把内部空间想象为可停留、可交流、可举办活动的社区。大空间中的活动类型可随时间变化，既支持企业办公与科研，也支持展览、教育、公共事件和日常休闲。

**（3）通过科学环境分析决定围护比例。**

项目利用计算机模型匹配采光、热工和声学需求，并通过实心面板、透明面板、窗洞和屋面渗透性的组合形成不同空间类型。立面和屋面的开口不是统一处理，而是依据使用性质和环境性能进行分区控制。

**（4）把绿化作为室内气候基础设施。**

建筑内部设置四个城市森林，提供遮阴和公共休息空间，同时降低屋面热负荷、改善局部微气候。屋顶约 4MW 光伏阵列为园区提供可持续能源；项目整体改造据报道节省约 90,000 吨隐含碳。

### 3. 对干煤棚设计的可借鉴点

1. **保留屋架和柱列作为“公共屋盖”**：干煤棚的 216m 长柱网不应被大量隔墙切碎，可把结构作为连续公共街的空间秩序。
2. **采用“盒子嵌入大空间”**：商业、展览、餐饮等可做成独立体量，避免新建隔墙覆盖工业尺度。
3. **将中部高大空间留作公共事件场地**：展览开幕、市集、演出、工业遗产展示等活动可共享同一条主街。
4. **首层绿化应承担环境性能**：在煤棚内形成成片乔木、雨水花园和可遮阴休息岛，而不是仅靠外围绿化率达标。
5. **先做环境模拟再定开口**：广州湿热、多雨且临江，应重点模拟东南风、横向穿堂风、暴雨排水和西晒，决定侧墙可开启界面与屋面通风口。

### 4. 局限与转化条件

Tonsley 是较大尺度、分期开发的园区更新项目，资金、能源系统和产业导入条件较好。干煤棚设计规模更集中，因此不宜照搬“园区级”技术系统，而应提炼为：连续公共空间、可变插入体、室内绿化、可分时运营和环境性能驱动的围护设计。

## 案例二：南京压缩机厂保护与更新——尤家凹社区中心

### 1. 项目基本信息

- **项目**：南京压缩机厂一般历史地段历史建筑保护与更新——尤家凹居住社区中心
- **地点**：江苏南京
- **设计**：东南大学建筑学院城市与建筑设计工作室（SEU-ARCH UAG）
- **设计阶段**：2019—2022 年；建成约 2023 年
- **建筑面积**：约 22,000㎡
- **原有性质**：20 世纪 50 年代建厂、80 年代形成的压缩机厂区；列入南京工业遗产保护规划二类工业遗产
- **保留对象**：四栋厂房、两处构筑物、林荫道、气力输送塔、循环水池等
- **新功能**：社区服务、文化活动、体育、医疗养老、小型商业、菜场、育儿等
- **主要材料**：陶砖、ETFE 膜、穿孔铝板

项目面对的是被居住区包围的旧厂区。更新不是单栋建筑翻新，而是通过保留厂房群、林荫道和生产构筑物，将原有生产流程转译成社区日常生活网络。

### 2. 核心空间策略

**（1）以“保留群体格局”代替单体复原。**

设计保留四栋厂房和两处构筑物，并把厂区原有林荫道作为重要空间资源。更新对象包括建筑、构筑物、树木和路径，工业遗产的价值由单体扩大到整体格局和记忆线路。

**（2）以“云影长廊”建立新旧之间的公共连接。**

白色长廊插入两栋工业遗迹之间，形成连续的公共轴线。它既是遮阳避雨的步行空间，也是连接社区文化、体育、商业和服务功能的交通骨架。新构件具有明确的当代识别性，同时不复制旧厂房的砖墙语言。

**（3）保留生产流程遗存，转化为场所标志。**

气力输送塔被保留并置于主入口轴线尽端，成为园区的视觉终点和工业记忆标志。原循环水池被改造成下沉广场，承载广场舞、篮球、轮滑等开放活动，使生产设施转化为社区公共设施。

**（4）在不改变历史外观的条件下进行结构加固。**

项目研究了历史砖墙抗震加固，采用植筋拉结等方式提高结构安全性，同时尽量保持外立面完整。新旧部分通过构造分界和材料差异形成可读性。

**（5）复合功能提升日常使用频率。**

社区中心并非单一展馆，而是把医疗养老、体育、文化、商业和育儿等高频服务导入旧厂区，使工业遗产进入居民日常生活，避免只在节庆或参观时使用。

### 3. 对干煤棚设计的可借鉴点

1. **把原有输煤廊道、挡煤墙、码头和行车轨道作为遗产网络**：不只保留煤棚主体，还应把生产流程遗存串入参观和公共活动路线。
2. **设置一条可识别的新公共构件**：可在干煤棚南侧或中部设置连续轻型雨棚、空中环廊或观江平台，承担交通、遮阳和公共活动功能。
3. **将设备遗存变成空间节点**：原行车轨道、吊车构件和煤斗可转译为展陈、灯光或观景节点，而不是全部拆除。
4. **把雨水设施做成公共景观**：借鉴循环水池改造为下沉广场的思路，将广州暴雨径流组织为下沉绿地、可淹没花园和阶梯看台。
5. **采用新旧材料对话**：保留混凝土、钢网架和煤炭肌理，新加构件可使用轻钢、穿孔板、半透明膜或再生砖，明确表达新旧关系。
6. **用社区级功能提高开放空间使用率**：除了展览和商业，应加入社区课堂、运动、亲子、老年活动和滨江休闲，使煤棚全年、全天候使用。

### 4. 局限与转化条件

尤家凹社区中心的功能与居住社区高度绑定，服务半径和居民需求与干煤棚的滨江公共综合体不同。干煤棚更适合把社区服务转化为公共文化、展览、餐饮、活动和滨江休闲，同时保留少量面向周边居民的日常功能。

| 更新尺度 | 大型产业园区与主厂房 | 多栋厂房与社区中心 | 建筑单体与场地遗产网络并重 |

| 交通组织 | 大屋盖下的开放活动与灵活分区 | 云影长廊形成主轴，步行桥连接厂房 | 首层公共街 + 二层环廊 + 两端入口 |

| 材料表达 | 透明/实心围护按性能配置 | 陶砖、ETFE、穿孔铝板形成新旧对话 | 混凝土、钢、穿孔板、半透明膜分层表达 |
| 生态策略 | 采光、热工、声学、CFD、光伏 | 被动遮阳、绿荫、旧水池景观化 | 广州湿热气候下重点做通风、遮阳、雨洪和绿化 |

## 对干煤棚方案的综合转译

### 1. 空间原型：一条“工业公共街”

以首层东西向公共街为主线，保持 216m 纵深的连续体验。零售、展览、工作坊、餐饮和公共休息作为可开可合的插入盒子布置在柱网之间，中央保持可举办大型活动的完整空间。

### 2. 交通原型：地面主街 + 空中环廊

首层承担无障碍通行、展览游逛和雨水花园联系；二层设置连续环廊，把餐饮、观江平台和屋顶花园串联起来。两端入口和中部交通核心形成分段疏散及独立运营条件。

### 3. 绿化原型：室内森林 + 滨江雨水花园

借鉴 Tonsley 的室内城市森林与尤家凹的林荫道、下沉广场，干煤棚可形成三层绿化系统：

- 首层：乔木绿岛、雨水花园、可淹没下沉庭院；
- 二层：连续空中花园、遮阳种植槽、观江平台；
- 屋面：光伏与轻型绿化结合，控制热负荷并收集雨水。

### 4. 新旧关系：让新增构件“可读、可逆、可维护”

新增盒子和环廊应尽量采用独立受力、少量落柱、可拆卸连接，避免破坏原排架柱与网架。新构件使用轻质钢结构、穿孔铝板、ETFE 或半透明板材，形成与粗犷混凝土结构的清晰对照。

### 5. 后续分析建议

1. 用 Ladybug/Honeybee 或其他日照工具比较“全开敞、局部围合、半透明围护”三种方案；
2. 用 CFD 或简化风环境模拟检验东南风穿堂效果和中庭热舒适性；
3. 对暴雨情景进行雨水花园、下沉广场和溢流路径推演；
4. 在平面深化阶段建立“公众、餐饮、后勤、消防”四类流线图；
5. 对原有混凝土柱、网架、行车轨道和附属构筑物建立遗产价值分级表。
