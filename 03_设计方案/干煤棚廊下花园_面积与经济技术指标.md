# 干煤棚廊下花园｜面积与经济技术指标（概念估算）

## 面积核算基础

本表采用现阶段概念包络 **216m × 36m** 进行估算，实际建筑长度、宽度、柱距和楼板边界需以原始 CAD 和结构复核为准。

| 指标 | 计算 | 概念值 |
|---|---:|---:|
| 原煤棚首层包络/屋盖覆盖面积 | 216 × 36 | 7,776㎡ |
| 首层功能房间面积 | 概念分区汇总 | 4,032㎡ |
| 首层公共开放、步道及绿化空间 | 7,776 − 4,032 | 3,744㎡ |
| 首层公共开放空间比例 | 3,744 ÷ 7,776 | 48.1% |
| 二层局部平台面积 | 概念分区汇总 | 1,188㎡ |
| 二层平台占首层包络比例 | 1,188 ÷ 7,776 | 15.3% |
| 全屋盖下楼板面积（首层 + 局部二层） | 7,776 + 1,188 | 8,964㎡ |
| 新增功能建筑面积（不含首层公共开放区） | 4,032 + 1,188 | 5,220㎡ |
| 新增功能面积与首层包络比 | 5,220 ÷ 7,776 | 67.1% |
| 首层绿化/渗透目标 | 3,744 × 35% | 约1,310㎡ |

“新增功能建筑面积”与“全屋盖下楼板面积”采用不同统计口径，不能直接替代法定计容建筑面积。最终以规划、消防和建筑面积计算规范核定。

## 需要在下一阶段校核的指标

1. 用 CAD 核定真实建筑面积、楼板开口面积和二层平台边界；
2. 根据结构鉴定确定原柱、屋架和屋面修缮范围；
3. 根据餐饮、展览和活动运营需求核定机电、排烟、厨房设备和消防投入；
4. 用种植土厚度、排水层、灌溉方式和植物密度校核绿化目标面积；
5. 依据当地规划、消防、无障碍和建筑面积计算规则重新确认法定技术指标。
