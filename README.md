# ARC｜建筑学研究生项目仓库

本仓库用于管理建筑学研究生阶段的研究、案例分析、设计推演、图纸与最终交付成果。

## 项目状态
- **仓库**：`zuo-2002/ARC`
- **阶段**：初始化占位结构
- **默认分支**：`main`
- **当前版本**：`v0.1.0`

## 目录说明
| 目录 | 用途 |
|---|---|
| `docs/` | 项目说明、任务书、研究方法与阶段记录 |
| `research/` | 文献、案例分析、现场调研与资料索引 |
| `drawings/` | CAD、分析图、平面/立面/剖面等图纸源文件 |
| `deliverables/` | PPT、PDF、展板、汇报图像等可交付成果 |
| `assets/` | 参考图片、底图、纹理与其他素材 |
| `archive/` | 旧版本与不再作为当前成果的文件 |

## 建议工作流
1. 在 `docs/project-brief.md` 中记录任务目标、基地与限制条件。
2. 将原始资料放入 `research/sources/`，并在 `research/README.md` 登记来源。
3. 每个案例在 `research/case-studies/` 建立独立 Markdown 文件。
4. 将 CAD、分析图和建筑图纸按类型放入 `drawings/`。
5. 将可提交版本放入 `deliverables/`，文件名包含日期和版本号。
6. 大幅修改前，把旧版本移入 `archive/`。

## 文件命名建议
`YYYYMMDD_项目简称_内容_版本.ext`，例如 `20261013_ARC_案例分析_v01.pptx`。
